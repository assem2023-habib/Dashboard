# لوحة تحكم إدارية تفاعلية - Elzero Dashboard

## نظرة عامة

**Elzero Dashboard** هو نموذج لوحة تحكم إدارية حديثة ومتجاوبة، مصممة باستخدام HTML5 وCSS3 مع أيقونات Font Awesome. يوفر هذا المشروع واجهة مستخدم نظيفة ومنظمة لإدارة المشاريع، المهام، والإحصائيات المختلفة.

![Dashboard Preview](imgs/dashboard-preview.png)

## المميزات الرئيسية

### 📊 لوحة التحكم الرئيسية

- **إحصائيات عامة**: عرض عدد المشاريع، الأرباح، والإنجازات
- **الأهداف السنوية**: تتبع الأهداف بالنسبة المئوية مع مؤشرات بصرية
- **إدارة التذاكر**: متابعة حالة تذاكر الدعم الفني

### 📰 المحتوى الديناميكي

- **آخر الأخبار والتحديثات**
- **المهام المعلقة والمكتملة**
- **إحصائيات البحث الشائع**
- **الملفات المرفوعة مؤخراً**

### 👥 إدارة المستخدمين

- **متابعة تقدم المشاريع**
- **جدولة التذكيرات**
- **إحصائيات وسائل التواصل الاجتماعي**

## التقنيات المستخدمة

- **HTML5** - بناء الهيكل الأساسي
- **CSS3** - التنسيقات والتصميم المتجاوب
- **Font Awesome 6.4.0** - الأيقونات والرموز
- **CSS Grid & Flexbox** - تخطيط متجاوب
- **CSS Variables** - نظام ألوان مرن ومنظم

## هيكل المشروع

```
My-Test_WebSite/
├── index.html          # الصفحة الرئيسية (Dashboard)
├── profile.html        # صفحة الملف الشخصي
├── project.html        # إدارة المشاريع
├── course.html         # الدورات التدريبية
├── friend.html         # قائمة الأصدقاء
├── file.html          # إدارة الملفات
├── plan.html          # الخطط والاشتراكات
├── setting.html       # الإعدادات
├── Css/               # مجلد التنسيقات
│   ├── normalize.css  # إعادة تعيين التنسيقات
│   ├── frame-work.css # إطار العمل الأساسي
│   └── master.css     # التنسيقات الرئيسية
├── imgs/              # مجلد الصور والأيقونات
└── fontawesome-free-6.4.0-web/ # مكتبة Font Awesome
```
